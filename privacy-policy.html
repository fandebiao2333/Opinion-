隐私政策

最后更新：2024年

概述

Opinion ↔ Polymarket 价格助手（"本扩展"）尊重您的隐私。本隐私政策说明了我们如何处理您的信息。

数据收集

本扩展不收集、不存储、不传输任何用户个人信息。

数据使用

  • 本扩展仅在您访问 Opinion 市场页面（app.opinion.trade）时运行
  • 扩展仅读取页面标题文本，用于查询 Polymarket 公开 API
  • 所有查询的数据均为公开信息，不涉及任何个人隐私
  • 扩展不会记录您的浏览历史、搜索记录或任何其他个人信息
  • 扩展不会追踪您的行为或向第三方发送任何数据

数据存储

  • 扩展仅使用 Chrome 的本地存储 API 存储必要的配置信息
  • 所有数据仅存储在您的本地设备上
  • 不会将任何数据同步到云端或任何服务器

第三方服务

本扩展会访问以下第三方服务：

  • Polymarket API（gamma-api.polymarket.com）：用于查询公开的市场价格数据
  • GitHub（raw.githubusercontent.com）：用于加载映射配置文件

这些服务均为公开 API，不涉及用户个人信息。

权限说明

  • scripting：用于在 Opinion 页面注入内容脚本，实现价格查询功能
  • storage：用于存储配置和缓存数据，提升性能
  • 访问 app.opinion.trade：扩展需要在此域名运行
  • 访问 gamma-api.polymarket.com：查询 Polymarket 公开的价格数据
  • 访问 raw.githubusercontent.com：加载远程映射配置文件

联系信息

如有任何隐私相关问题，请通过 Chrome Web Store 开发者页面联系我们。

变更通知

我们可能会不定期更新本隐私政策。重大变更将通过扩展更新通知用户。
