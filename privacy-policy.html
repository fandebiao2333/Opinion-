隐私政策 最后更新：2025年12月 数据收集 本扩展程序（Opinion价格助手）不会收集、存储或传输任何个人身份信息。 本地存储的数据 本扩展程序仅在您的浏览器本地存储以下非个人数据，用于改善用户体验： - 排序偏好：您选择的排序方式（默认、按价格排序等） - 主题偏好：您选择的界面主题（浅色/深色） 这些数据仅存储在您的浏览器本地，不会发送到任何服务器，也不会被第三方访问。 网络请求 本扩展程序会进行以下网络请求： 1. Polymarket API：用于获取市场数据（仅读取，不发送用户数据） 2. GitHub Raw URL：用于加载事件映射配置（仅读取，不发送用户数据） 这些请求仅用于获取公开的市场信息，不包含任何个人身份信息。 数据使用 - 本地存储的偏好设置仅用于在您的浏览器中保存您的选择 - 不会将任何数据用于广告、分析或追踪 - 不会与第三方共享任何数据 数据删除 您可以随时通过以下方式删除本地存储的数据： 1. 在 Chrome 中卸载本扩展程序 2. 在浏览器开发者工具中清除 localStorage 联系我们 如有任何关于隐私的疑问，请通过 GitHub Issues 联系我们。 本隐私政策可能会更新，更新后的版本将在此页面发布。
